# Market product photos — 2026-10-07

This pack contains `manifest.json` and 146 WebP illustrations in 17 exact
MarketPoint directories. Each `<slug>.webp` corresponds to the identical Product
slug and MarketPoint slug in the manifest; SHA-256 verifies the source bytes.
`manifest.json` and this README are the only pack metadata files.

These are `AI_PLACEHOLDER` assets. Existing product photos are never replaced.
The pack does not create products or change prices, priceStatus or MarketPoint
data. The target catalogue must already contain the products before apply.

The importer reads this deployed pack, not the local `product-photo-source/`
staging directory. See [import instructions](../README.md) for audit, dry-run,
apply, validation and separately authorized future production use.
